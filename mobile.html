SETUP AWAL

  1. ➤ Ketika Sudah Berhasil Mendaftar dan Login, Langkah Selanjutya
  2. ➤ Masuk Ke Menu Produk Kasir dan Buat Folder Di Pojok Kanan Atas
  3. ➤ Klik Buat Folder, dan akan diarahkan ke Browser Penyimpanan Komputer
  4. ➤ Buat Nama Folder Sesuai Nama Toko Anda, Contoh Nama Folder TOKO INOYA
  5. ➤ Akan Otomatis Membuat sub Folder di Folder yg Anda Buat Tadi, Sub Folder: Rekap, Produk, Kasir
  6. ➤ Semua Data Transaksi Kasir, Rekap, Backup Manual akan Masuk ke dalam Folder yang sudah di buat oleh Anda
  7. ➤ Jika Data Produk Tehapus Di folder Yg Anda Buat, Maka secara Otomatis Menampilkan Data dari Database Online yg tersimpan, & Lakukan Backup Manual Kembali, di file yang terhapus
  8. ➤ Disaranakan Membuat Folder di Data : D komputer & Di Data: C komputer (tidak Disarankan)

MENU PRODUK KASIR

  1. ➤ Icon Backup Warna Biru di pojok kanan bawah (Untuk Membackup Data Produk) Disarankan Rutin Membackup data Produk, Jika Menambahkan Produk baru.
  2. ➤ Buat Folder Dikomputer Anda Beri Nama Backup Produk (File yg Sudah Dibackup Pindahkan Ke Folder Backup Tersebut, buat jaga Jaga)
  3. ➤ Icon Import Warna Hijau di pojok Kanan Bawah (Untuk Mengimport/Memasukan Kembali Data yang sudah di Backup di Folder backup Produk)
  4. ➤ Usahakan Rajin / Rutin Membackup Data ketika Menambahkan Produk Baru.
  5. ➤ Kehilangan data bukan Tanggung Jawab Developer, Developer Sudah Menghimbau.

MENU SETING

  1. ➤ Atur Nama Toko, Alamat Toko, Nomor Handpone (Untuk Dicetak Di Struk)
